# Versiones de publicación

Imágenes que la web sirve desde la propia colección, cuando no pueden enlazarse desde la institución
que las publica. En la columna `filename` de la hoja se escribe solo el nombre del archivo, que es el
`objectid` con su extensión: `garcilaso-1604.jpg`.

Son derivados de la copia de trabajo de `_coleccion/02-trabajo`, en JPEG y de unos 1600 px de lado
largo, para que la web cargue con rapidez.
